# Tokens

All tokens are generated by `tool/generate_theme.dart` from the visual refresh theme preset that ships inside `@cloudscape-design/components` (1,173 tokens, about twice what the public `@cloudscape-design/design-tokens` package exposes), so every component can use exactly the value Cloudscape uses.

## Colors

`CsColor` has 807 tokens: the palette (`grey500`, `blue600`), the data visualization palette (`chartsRed300`, `chartsPaletteCategorical1`...), and the semantic tokens components use (`textBodyDefault`, `backgroundButtonPrimaryDefault`, `borderInputFocused`). The Cloudscape name minus its `color` prefix is the Dart name.

```dart
final c = context.cs.colors;
Container(color: c.backgroundContainerContent);
Text('Error', style: TextStyle(color: c.textStatusError));
```

`CsColorSchemes.light` and `.dark` hold the values; `CsColorSchemes.contextOverrides(context, brightness)` holds what each visual context recolors.

## Spacing

| Token | Value | Use |
| --- | --- | --- |
| `CsSpace.xxxs` | 2 | Hairline gaps |
| `CsSpace.xxs` | 4 | Icon to text, label to control |
| `CsSpace.xs` | 8 | Between buttons |
| `CsSpace.s` | 12 | Field horizontal padding |
| `CsSpace.m` | 16 | |
| `CsSpace.l` | 20 | Container horizontal padding |
| `CsSpace.xl` | 24 | |
| `CsSpace.xxl` | 32 | Between page sections |
| `CsSpace.xxxl` | 40 | |

`CsSpace` also has the named fixed tokens (`fieldHorizontal`, `containerHorizontal`, `buttonFocusOutlineGutter`...). Spacing that changes with density lives on the theme: `context.cs.space.scaledM` is 16px comfortable and 12px compact; so are `sizeVerticalInput` (32/28), `buttonVertical`, `fieldVertical`, `containerContentVertical` and the rest of `CsDensityTokens`. `CsDensityTokens.compactTable` holds what tables use in compact content density.

## Type

`CsTypeScale` pairs each font size with its line height, weight and letter spacing:

| Step | Size / line | Weight |
| --- | --- | --- |
| `bodyS` | 12 / 16 | 400 |
| `bodyM` | 14 / 20 | 400 |
| `headingXs` | 14 / 18 | 700 |
| `headingS` | 16 / 20 | 700 |
| `headingM` | 18 / 22 | 700 |
| `headingL` | 20 / 24 | 700 |
| `headingXl` | 24 / 30 | 700 |
| `displayL` | 42 / 48 | 700 |
| `displayXl` | 64 / 72 | 400 |

Use `context.cs.text(CsTypeScale.headingM)` or, for semantic text, `CsBox(variant: CsBoxVariant.h3)`. Raw values are in `CsFontTokens`.

## Borders and radii

`CsBorderRadius` (`button` 20, `container` 16, `input` 8, `dropdown` 8, `badge` 4...), `CsBorderWidth` (`button` 2, `field` 1, `popover` 2, `fieldStatusInlineStart` 8...) and `CsBorderLine` (divider and focus ring widths).

## Shadows

`context.cs.shadows` (`CsShadows.light` / `.dark`): `dropdown`, `popover`, `modal`, `sticky`, `stickyEmbedded`, `panel`, `splitBottom`, `splitSide`, `container`... Resting containers have none in visual refresh.

## Motion

`CsDurations` (`responsive` 115ms, `expressive` 165ms, `complex` 250ms, `showPaced` 180ms, `fast` 90ms...) and `CsCurves` (`responsive`, `expressive`, `sticky`, `showPaced`...). See [Motion](motion.md).

## Breakpoints

`CsBreakpoint`: `xxs` 465, `xs` 688 (the mobile breakpoint), `s` 912, `m` 1120, `l` 1320, `xl` 1840. `context.csIsNarrow` is true at 688px and below.
